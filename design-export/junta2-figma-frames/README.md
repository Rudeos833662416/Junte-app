# Junta2 · Frames editables para Figma

Paquete con 16 frames SVG de 390 × 844 px para arrastrar a Figma. Las formas, colores y textos se conservan como capas editables.

## Importación

1. Descarga y descomprime el ZIP.
2. En Figma, crea una página llamada `Junta2 · Exportación desde app`.
3. Arrastra los `.svg` a la página.
4. Entra al grupo importado para modificar textos, colores y componentes.

## Incluye

Acceso, inicio, amigos, solicitudes, mapa, actividad, eventos, perfil, estados, mensajes, chat privado, perfil público, escáner QR y tres estados de notificación: mensaje con respuesta rápida, solicitud con aceptar/ver perfil y brindis con acceso al mapa.

Los nombres y datos son de ejemplo para reemplazarlos en el prototipo.
